Vrinda_Store_Data_Analysis_Using_Excel
📌 Project Overview

Vrinda Store Data Analysis Using Excel is a business analytics project designed to transform raw retail sales data into actionable insights through structured data cleaning, KPI calculation, and an interactive Excel dashboard. The project focuses on enabling non-technical stakeholders to make informed inventory, pricing, and sales decisions using a low-cost, Excel-based solution.

❓ Problem Statement

Small retail stores often collect large volumes of sales, product, and customer data but lack simple and affordable tools to convert this data into meaningful business insights. Without consolidated KPIs and visual dashboards, store owners struggle with inventory optimization, pricing strategy, and identifying top-performing products or sales periods—leading to stockouts, excess inventory, and missed revenue opportunities.

💡 Solution

This project delivers a single-file Excel analytics solution that:

Ingests raw sales data

Performs data cleaning and transformation

Computes business-critical KPIs

Presents insights through an interactive dashboard using pivot tables, slicers, and charts

The solution empowers store managers and business users to answer key business questions without coding or expensive BI tools.

🎯 Key Objectives

Ingest and validate raw sales data (.csv / .xlsx)

Clean and transform data (date parsing, missing values, category normalization)

Build robust KPIs such as:

Total sales

Gross profit & margin

Units sold

Average Order Value (AOV)

Repeat customer rate

Sell-through rate

Create interactive dashboards using pivot tables, slicers, and charts

Export summary reports for weekly and monthly decision-making

📊 Core KPIs & Metrics

Total Revenue (by selected period)

Gross Profit and Gross Margin (%)

Units Sold (by product, category, and time)

Average Order Value (AOV)

Top 10 Products by Revenue and Units Sold

Sell-through Rate (sold vs stocked)

Inventory Days of Supply (if inventory data is available)

Repeat Purchase Rate (if customer data exists)

Sales Trends (daily / weekly / monthly with MoM & YoY comparison)
